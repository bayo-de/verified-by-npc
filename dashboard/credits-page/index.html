How checks work

  1. Buy a pack, or start the Verifier Pass, on this page. Payment runs through Stripe.
  2. Get one code on this page, and by email if you gave an address.
  3. Paste the code into the NPC Verify extension. The extension shows your balance and spends from it only after your 10 free checks are used.
  4. The Pass refills monthly. While your Verifier Pass runs, registry checks are unlimited and the AI generation allowance refills on the same code each month. The unused part of the allowance rolls into the next month once, then it expires.
  5. Checking an image you already checked is free. The extension remembers, and the ledger will not charge the same image twice.
  6. A check that cannot complete costs nothing. If the registry cannot be reached or an answer cannot be verified, no check is spent.

How referrals work

Every code comes with a personal referral link. Share it, and when a friend joins through your link you each get 10 checks. Registering a first work or agent earns the 25-check registration bonus. When a friend you brought makes a first purchase, you get 100 checks. Referral earnings cap at 500 checks a month. Bonus checks can pay for registry checks and for AI generation checks.
