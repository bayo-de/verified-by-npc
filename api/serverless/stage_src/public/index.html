NPC Verification API (demo)

The demo verification surface behind the Verified by NPC plugin. Read-only: it answers whether a product, credential, claim, or AI agent is verified against NPC Labs demo records. Every response is cryptographically signed by NPC Labs.

Demo data only. Fixtures are fictional and labeled demo-. Unknown subjects return "unknown", never a guess.
  • GET /v1/health - liveness
  • GET /v1/keys - public signing keys (verify any response offline)

Verification lookups need the demo API key (used by the plugin):
GET /v1/products/demo-tag-001
GET /v1/credentials/demo-cred-001
GET /v1/agents/demo-agent-001/attestation
POST /v1/claims/verify
