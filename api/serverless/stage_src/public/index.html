NPC Verification API

The live API behind Verified by NPC. Register agents and content, retrieve their signed records, and verify NPC signatures against the public keys published here. Unknown subjects return "unknown", never a guess.

  • GET /v1/health - service status
  • GET /v1/keys - public signing keys (verify any response offline)

Registration and record lookup:
POST /v1/register/agent
POST /v1/register/content
GET /v1/records/{record_id}
POST /v1/mcp - hosted MCP endpoint
