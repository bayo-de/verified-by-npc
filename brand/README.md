# "Verified by NPC" mark, brand artwork

**Status: DRAFT for internal review. Not for public use.**

Public use of this mark requires two things, in this order: Bayo's explicit
approval of the final artwork, then counsel clearance. Counsel review is
already on Anibal's list. Until both land, this folder is internal only.

This mark is separate from the placeholder assets in
`plugins/openai/assets/`. Those placeholders stay in place until approved
artwork replaces them. Nothing here ships anywhere on its own.

## What the mark is

One gesture: a single orange check. No circle, no badge, no blue checkmark.
The stroke tapers from a confident entry to a light exit, and the long arm
finishes with a forward slice. The color is NPC Orange, `#FF6A00`.

The mark is always the check alone. The words "Verified by NPC" sit next to
it in type, never baked into the artwork, so the mark never depends on a font.

## Files

- `svg/verified-by-npc-primary.svg`: primary mark, NPC Orange. Source file.
- `svg/verified-by-npc-small.svg`: small-size variant, heavier cut for
  16 to 32 px. Source file.
- `svg/verified-by-npc-mono-black.svg`: monochrome black (`#181818`),
  for one-color use on light grounds. Source file.
- `svg/verified-by-npc-mono-white.svg`: monochrome white (`#FFFFFF`),
  for one-color use on dark grounds. Source file.
- `png/<variant>/verified-by-npc-<variant>-<size>.png`: PNG exports for
  each variant at 16, 32, 64, 128, 256, 512, and 1024 px.
- `preview/verified-by-npc-preview.png`: review contact sheet: all variants,
  a size ladder at true pixel sizes, and dark-ground samples.
- `tools/make_mark.py`: generator script. The mark is defined by geometry
  parameters in this file, so it can be rebuilt exactly from numbers.
- `tools/make_preview.py`: builds the review contact sheet.
- `USAGE.md`: usage notes: clear space, minimum size, what the mark must
  never be combined with, and the rule that it only appears next to signed,
  verifiable verdicts.
