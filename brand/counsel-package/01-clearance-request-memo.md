**Re:** Clearance request for public use of the Verified by NPC mark

## What the mark is

The Verified by NPC mark is a single original check drawn in NPC Orange
(#FF6A00). The stroke tapers from a confident entry to a light exit, and
the long arm finishes with a forward slice. There is no circle, no badge,
no blue checkmark, and no container shape. Four production variants are
included in this package: the primary orange mark, a heavier small-size
cut for 16 to 32 px use, and black and white monochrome versions for
one-color use. The artwork is final and approved by NPC Labs as of
2026-10-06. Source SVGs, PNG exports at seven sizes, and a review contact
sheet are enclosed.

## What it signifies

The mark appears only next to signed, verifiable NPC verdicts: verdicts
that carry a valid NPC signature checkable against our published keys and
that point to an attestation ID or verification page anyone can check.
The enclosed verdict-integrity rule defines exactly what the mark does
and does not signify. It is a verification mark in the descriptive sense:
it tells the viewer the item beside it can be verified, not that NPC
endorses anything beyond the verdict's own scope and time bounds.

## Where it will be used

- **NPC agent plugins:** the OpenAI plugin and the MCP server (npc-verify),
  in UIs and output where a verdict is presented.
- **The Verified by NPC dashboard web app,** alongside presented verdicts.
- **Verification reports and verification pages** linked from attestations.

The mark will not appear anywhere public until counsel clears it. It is
not currently in public use.

## What clearance is requested

1. **Trademark clearance:** a likelihood-of-confusion review of the mark
   against existing marks in the relevant classes, so we can use it
   publicly with confidence.
2. **Right to use:** your view on our right to use this mark publicly as a
   program, and whether any filing (trademark application, certification
   or standard mark, or otherwise) is recommended to protect it.
3. **Program-level coverage:** confirmation that clearance covers the
   mark's public use as a program, with individual placements governed by
   our enclosed usage rules and Bayo's approval of each new use, so we do
   not need to return for each placement.
